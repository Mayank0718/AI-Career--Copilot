# 🤖 AI Career Copilot

An AI-powered Resume Analyzer built using **Python, Flask, and Google Gemini AI**.

The application analyzes resumes, calculates ATS score, identifies strengths and missing skills, recommends job roles, generates interview questions, and exports a professional PDF report.

---

## 🚀 Features

- 📄 Upload Resume (PDF)
- 🤖 AI Resume Analysis
- 📊 ATS Score
- 💪 Strengths Analysis
- ❌ Missing Skills Detection
- 🛠 Technical Skills Extraction
- 💼 Best Job Roles Recommendation
- 🚀 Career Suggestions
- 🎤 AI Interview Questions
- 📥 Download PDF Report
